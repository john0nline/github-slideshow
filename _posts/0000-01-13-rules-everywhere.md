Put each rule at the level where it belongs:

| If the rule applies to… | Put it in… | Example |
|---|---|---|
| **Everything you do** | Profile preferences | "Use South African English and the SAST time zone" |
| **Facts about you** | Account memory | "I'm an AE covering mid-market logistics" |
| **One account or area** | Project instructions | "Acme's CFO is the economic buyer" |
| **One repeatable task** | A skill | "How I write a call recap" |

**Rule of thumb:** if you've typed it in three different chats, save it somewhere
