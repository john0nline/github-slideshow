title: "Keeping a project current"
---

A project is only as useful as its latest information

- **After each call:** add the notes or transcript
- **Weekly:** ask "Update the account summary using this week's notes", then save the result as a file in the project
- **Monthly:** remove stale files and update the instructions
- **When the deal closes:** archive the project, or keep it for renewal

**Tip:** a one-page "account summary" file saves Claude reading every note each time
