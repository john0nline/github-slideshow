title: "Part 1: What is a project?"
---

A workspace that keeps everything for one area of work together:

- **Instructions:** how Claude should behave in this project
- **Knowledge:** files Claude can refer to in every chat here
- **Chats:** your conversations, grouped in one place
- **Its own memory:** what Claude learns here stays here

Every chat you start inside the project begins with all of this already loaded
